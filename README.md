# Chzzk Look

치지직에서 방송 중인 라이브를 조건별로 필터링해서 찾아주는 데스크톱 프로그램입니다.

시청자나 팔로워가 적은 소규모 방송, 특정 태그가 달린 방송 등 치지직 사이트에서 직접 찾기 번거로운 방송들을 한눈에 모아볼 수 있습니다.

## 필요한 것

- **Windows 10 / 11** - 화면 표시에 Edge WebView2를 사용합니다. 대부분 이미 깔려 있고, 없으면 [여기서](https://developer.microsoft.com/microsoft-edge/webview2/) 설치하면 됩니다.
- **Python 3.10+** - 3.12에서 테스트했습니다.
- **치지직 Open API 키** - Client ID / Client Secret이 필요합니다. 아래 발급 방법을 참고하세요.

## 설치

```bash
cd Chzzk_Look
pip install -r requirements.txt
```

`requests`, `pywebview`, `tzdata`가 설치됩니다.

## API 키 발급

1. [치지직 개발자 센터](https://developers.chzzk.naver.com/)에 네이버 계정으로 로그인
2. 애플리케이션 등록 후 **Client ID**와 **Client Secret** 확인
3. 프로그램 왼쪽 위 API 칸에 입력

> Secret은 비밀번호나 마찬가지입니다. 절대 다른 사람에게 공유하거나 인터넷에 올리지 마세요.

## 실행

```bash
python chzzk_look.py
```

개발자 도구를 같이 열고 싶으면 `--debug` 옵션을 붙이면 됩니다.

## 사용법

```
+---------------+---------------------------------------------+
| API           | 정렬 [시청자 적은 순]  [격자|목록]  찾기 [   ] |
| 카테고리/태그 |---------------------------------------------+
| 조건          |                                             |
| 패스 목록     |              검색 결과                       |
| [  검색  ]    |                                             |
+---------------+---------------------------------------------+
| 상태 표시줄                                 디버그 로그       |
+-------------------------------------------------------------+
```

### 조건 설정 (왼쪽 패널)

**카테고리 / 태그**

카테고리는 `전체`, `토크`, `게임`, `스포츠`, `기타` 버튼으로 빠르게 고를 수 있고, 입력칸에 직접 쓸 수도 있습니다. 쉼표로 구분하면 여러 개를 동시에 걸 수 있습니다. 예를 들어 `토크, 마인크래프트`라고 쓰면 둘 중 하나라도 해당하는 방송이 나옵니다.

`[목록]` 버튼을 누르면 현재 방송 중인 카테고리 이름을 불러와서 자동완성에 넣어줍니다.

태그도 쉼표로 여러 개 넣을 수 있고, "모두 포함"이면 전부 가진 방송만, "하나라도"면 하나만 맞아도 통과합니다. 부분 일치도 됩니다. `시참`을 넣으면 `발로시참`이나 `시참o` 같은 태그도 잡힙니다.

**필터 조건**

| 조건 | 예시 | 설명 |
|---|---|---|
| 시청자 | 0 ~ 2 | 현재 시청자 수 범위 |
| 팔로워 | 0 ~ 20 | 채널 팔로워 수 범위 |
| 방송시간 | 5시간 이하 | 방송 시작 후 경과 시간 |
| 최대 스캔 | 50000 | 몇 개의 라이브까지 훑어볼지 |

시청자가 적은 방송을 찾으려면 최대 스캔을 넉넉하게 잡아야 합니다. 라이브 목록이 시청자 많은 순으로 내려오기 때문에 소규모 방송은 뒤쪽에 있거든요. 보통 전체 라이브가 4천~6천 개 정도 됩니다.

**패스 목록**

결과에서 빼고 싶은 채널을 관리하는 곳입니다. URL이나 채널 ID(32자리)를 한 줄에 하나씩 넣으면 됩니다.

이 목록은 `skip.txt` 파일과 연동됩니다. 메모장으로 직접 수정해도 되고, 프로그램을 다시 열면 반영됩니다. `[파일 불러오기]`로 다른 txt 파일 내용을 합칠 수도 있습니다.

### 검색

`[검색]` 버튼이나 `Ctrl+Enter`, 또는 왼쪽 입력칸에서 `Enter`를 누르면 검색이 시작됩니다.

진행 상황은 아래 상태 표시줄에 표시되고, 도중에 `[중지]`나 `Esc`를 누르면 그때까지 확인한 결과만 보여줍니다.

### 결과 보기 (오른쪽 패널)

- **격자** / **목록** 보기를 전환할 수 있습니다.
- **정렬**: 시청자 적은 순 / 팔로워 적은 순 / 최근 시작 순 / 채널 이름 순
- **찾기**: 결과 내에서 추가로 거릅니다. 쉼표로 여러 단어를 넣으면 전부 포함된 항목만 표시합니다 (채널명, 제목, 카테고리, 태그 대상).
- 태그 검색에 걸린 태그는 초록색으로 강조됩니다.

각 방송 카드에서 할 수 있는 것:

- **열기** - 브라우저로 방송 페이지를 엽니다 (썸네일이나 제목 클릭도 동일)
- **링크복사** - 방송 URL을 클립보드에 복사
- **패스** - 패스 목록에 추가하고 결과에서 숨깁니다. 상태 표시줄의 `[되돌리기]`로 취소 가능

### 기타

설정은 바꿀 때마다 자동 저장됩니다. 상태 표시줄 오른쪽의 "디버그 로그"를 켜면 `debug.log`에 검색 과정과 오류가 기록됩니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| 조건 검색 | 카테고리, 태그, 시청자, 팔로워, 방송시간 조합 |
| 전체 스캔 | 시청자 적은 방송까지 빠짐없이 확인 |
| 시청자 수 갱신 | 결과 300개 이하일 때 현재 시청자 수를 다시 확인하고, 끝난 방송은 제외 |
| 팔로워 표시 | 필터를 꺼도 결과 5000개 이하면 팔로워 수를 함께 표시 |
| 패스 목록 | skip.txt로 관리, 결과에서 바로 추가하거나 되돌리기 |
| 보기 전환 | 격자/목록, 정렬, 결과 내 검색, 태그 강조 |
| 중지 | 검색 도중 멈추고 부분 결과 확인 |
| 자동 저장 | 설정 변경 시 settings.json에 즉시 반영 |
| 디버그 로그 | 켜고 끌 수 있으며, 2MB마다 새 파일로 교체 (최대 3개) |

## 설정 파일

`settings.json`은 프로그램이 알아서 만들고 관리합니다. 처음 쓸 때 `settings.example.json`을 복사해서 시작해도 됩니다.

```bash
copy settings.example.json settings.json
```

| 키 | 기본값 | 설명 |
|---|---|---|
| `client_id` | `""` | 치지직 Open API Client ID |
| `client_secret` | `""` | Client Secret (`save_secret`이 `true`일 때만 저장됨) |
| `save_secret` | `false` | Secret을 파일에 저장할지 여부 (평문 저장이라 주의) |
| `category` | `"토크"` | 카테고리, 쉼표로 여러 개 가능. 비우면 전체 |
| `max_total` | `10000` | 최대 스캔 개수 |
| `follower_enabled` / `min_followers` / `max_followers` | `true` / `0` / `10` | 팔로워 조건 |
| `viewer_enabled` / `min_viewers` / `max_viewers` | `true` / `0` / `1` | 시청자 조건 |
| `uptime_enabled` / `max_uptime_hours` | `false` / `5.0` | 방송시간 조건 |
| `tags` | `""` | 태그 검색어, 쉼표 구분 (최대 10개, 각 30자) |
| `tag_mode` | `"all"` | `all`이면 모두 포함, `any`면 하나라도 |
| `debug_log` | `true` | debug.log 기록 여부 |
| `sort` | `"viewers"` | `viewers` / `followers` / `recent` / `name` |
| `view` | `"grid"` | `grid` / `list` |

패스 목록은 settings.json이 아니라 `skip.txt`에 저장됩니다.

## 동작 방식

검색 버튼을 누르면 이런 순서로 돌아갑니다:

```
1. 라이브 목록 스캔      GET /open/v1/lives (20개씩, 최대 스캔 수만큼)
                         카테고리 조건으로 1차 필터링
2. 패스 목록 제외        skip.txt에 있는 채널 제거
3. 태그/시청자/업타임    가벼운 조건을 먼저 걸러서 이후 API 호출을 줄임
4. 팔로워 조회           GET /open/v1/channels (20채널씩 묶어서 요청)
5. 시청자 수 갱신        결과 300개 이하일 때만, 현재 시청자 수 재확인
                         이미 끝난 방송은 제외
6. 정렬 후 화면에 표시
```

Open API의 시청자 수는 약간의 딜레이가 있어서 5단계에서 사이트가 쓰는 공개 엔드포인트로 다시 확인합니다. 이건 비공식 API라 실패하면 기존 값을 그대로 씁니다.

일시적인 서버 오류(429, 5xx)나 네트워크 문제는 자동으로 최대 4번까지 재시도합니다.

## 사용 기술

| 분류 | 기술 | 역할 |
|---|---|---|
| 언어 | Python 3 | 전체 로직 |
| 화면 | pywebview + Edge WebView2 | HTML/CSS/JS UI를 데스크톱 창으로 표시 |
| 프론트엔드 | HTML, CSS, JavaScript (라이브러리 없음) | 입력 폼, 결과 카드/표, 상태바 |
| HTTP | requests | API 호출 (세션 재사용, 자동 재시도) |
| 병렬 처리 | ThreadPoolExecutor | 시청자 수 갱신을 10개씩 동시 요청 |
| 비동기 | threading | 검색 중 UI 멈춤 방지, 중지 처리 |
| 시간대 | zoneinfo + tzdata | 방송 시작 시각 한국 시간 기준 계산 |
| 로깅 | RotatingFileHandler | debug.log 기록, 2MB 단위 로테이션 |
| 저장 | json | 설정 파일 (임시 파일 -> 교체 방식으로 안전하게) |

**사용하는 API**

| 엔드포인트 | 유형 | 용도 |
|---|---|---|
| `GET /open/v1/lives` | 공식 Open API | 방송 중인 라이브 목록 |
| `GET /open/v1/channels` | 공식 Open API | 채널 팔로워 수 |
| `GET /service/v3/channels/{id}/live-detail` | 사이트 공개 주소 (비공식) | 현재 시청자 수, 방송 상태 |

화면(JS)에서 `window.pywebview.api.search()` 같은 식으로 Python 함수를 직접 호출하고, 검색 진행 상황은 Python 쪽에서 `window.evaluate_js()`로 화면에 전달합니다.

## 파일 구성

```
Chzzk_Look/
  chzzk_look.py           실행 파일. 창 띄우기, JS-Python 브리지, 입력 검증
  chzzk_core.py           API 호출, 필터링, 패스 목록, 설정 저장, 로그
  web/
    index.html             화면 구조
    style.css              스타일
    app.js                 화면 동작 (검색, 결과 표시, 정렬, 찾기, 패스)
  requirements.txt         필요한 패키지 목록
  settings.example.json    설정 예시 (비밀값 없음)
  settings.json            내 설정 (자동 생성, Secret 포함 가능 - 공유 금지)
  skip.txt                 패스 목록
  debug.log                디버그 로그 (켰을 때만 생성)
```

## 문제 해결

| 증상 | 해결 |
|---|---|
| `No module named 'webview'` | `pip install -r requirements.txt` |
| 창이 하얗게만 뜸 | WebView2 런타임을 설치하고 다시 실행 |
| 인증 실패 (401/403) | Client ID와 Secret이 맞는지 확인 |
| 결과가 너무 적음 | 최대 스캔을 늘리고 조건 범위를 넓혀보세요 |
| 카테고리가 안 맞음 | [목록] 버튼으로 실제 카테고리 이름을 받아서 써보세요 |
| 원인 모를 오류 | 디버그 로그를 켜고 다시 검색한 뒤 debug.log를 확인하세요 |

## 공유할 때 주의

`settings.json`에 Client Secret이 들어 있을 수 있습니다. GitHub에 올리거나 다른 사람에게 줄 때는 `settings.json`과 `debug.log`를 빼고, `settings.example.json`을 대신 포함하세요.
